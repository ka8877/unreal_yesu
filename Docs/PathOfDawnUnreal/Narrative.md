# 새벽의 길: 갈릴리의 첫 아침 — 서사와 각색 기록

제작 원본은 `SourceArt/PathOfDawnUnreal/Narrative/episode.json`이다. 34개 노드, 본문 3,794자, 중요한 선택 두 번, 결과 세 가지를 작성했다. 첫 플레이 약 5분은 도입 20초, 탐색, 읽기, 결과와 회귀를 합친 설계 목표다. 실제 Unreal 플레이 시간을 측정하지 못했으며 이 수치를 달성했다고 보고하지 않는다.

## 출처와 구분

- 참고 범위: **누가복음 5:1–11**. [USCCB 공개 본문](https://bible.usccb.org/bible/luke/5)을 2026-10-23에 확인했다.
- 원문 사건 순서: 호숫가의 사람들·두 배·그물을 씻는 어부들 → 시몬의 배에서 가르치심 → 가르침 뒤 깊은 곳으로 가라는 말씀 → 밤새 잡지 못한 시몬의 응답과 그물 내림 → 많은 고기·찢어질 듯한 그물·다른 배 동료의 도움 → 시몬의 놀람, 야고보와 요한, 안심시키심과 부르심 → 배를 뭍에 대고 따름.
- 본문을 직접 작성한 짧은 한국어로 요약한다. 특정 한국어 성경 번역문을 복사하거나 USCCB 영어 문장을 게임의 대사로 옮기지 않는다.
- `ContentKind`는 `성경 사건 요약`, `창작 연결 장면`, `가상 분기` 중 하나다. 모든 노드에 `ScriptureReference`, `SourceNote`가 있다.
- **예수님이 여행자에게 하는 모든 대사는 창작**이다. 각 노드의 `DisplayNote`에 “성경 직접 인용 아님”을 표시하고, UI는 콘텐츠 종류·출처 안내를 제공한다.
- 여행자, 시간 이동, 조사 사물, 밧줄 수선, 관계값, 선택, 회귀와 결과 화면은 허구다. 예수님의 얼굴도 창작적 재현이며 역사적으로 확인된 초상이라고 주장하지 않는다.
- 새벽빛은 미술적 설정이다. 누가복음 본문이 정확히 새벽 시각을 특정한다고 주장하지 않는다.
- 다른 복음서의 유사 장면, 특히 요한복음 21장의 부활 후 사건을 섞지 않는다.

타이틀의 시작 안내와 기록 화면에는 다음 문구를 표시한다.

> 성경의 사건을 바탕으로 구성한 창작 서사입니다. 여행자의 존재, 선택과 시간 회귀는 허구입니다.

## 플레이 흐름

1. **도착:** 물소리와 새벽 이미지·짧은 카메라 이동. 20초 도입은 건너뛸 수 있다.
2. **탐색:** 낡은 그물, 작은 배, 물가의 돌을 조사한다. 그물에서는 밧줄 한 조각을 한 번만 얻는다. 세 조사 후 시몬의 대화를 열어 핵심 정보를 놓치지 않게 한다.
3. **만남과 CP01:** 시몬과 여행자의 창작 대화, 예수님의 짧은 창작 연결 대사. 첫 선택 직전에 밧줄 1개·기본 관계·미수선 상태를 값으로 저장한다.
4. **첫 선택:** 선택 후 그물 또는 물가의 돌까지 직접 걸어가 E로 행동을 마친다. 선택 효과는 한 번만 적용하며, 그물 외형은 실제 매듭 행동을 마친 뒤 바뀐다.
5. **사건의 기록:** 시몬의 배에서의 가르침, 깊은 곳으로의 이동, 많은 고기, 시몬의 놀람을 원래 순서대로 요약한다. 복잡한 군중·항해는 일러스트와 환경음으로 압축한다.
6. **CP02와 둘째 선택:** 사건을 본 뒤 시몬에게 직접 돌아가 E로 두 번째 선택을 연다. 시몬 곁에 남거나 마을 쪽으로 떠난다. 떠나기를 고르면 돌길 끝의 마을 입구까지 걸어가 E로 아침을 돌아본 뒤 결과와 기억이 기록된다.
7. **결과와 회귀:** CP01/CP02로 되돌아가 다른 관점을 본다. 기억과 이미 본 결과는 감소하지 않는다. 한 번 결과를 본 뒤 첫 선택의 문구에 기억을 암시하는 한 줄이 반영된다.

## 분기와 실제 상태 계약

| 선택 1 | 선택 2 | 결과 | 구별되는 상태 |
|---|---|---|---|
| 시몬을 도움 (`HelpSimon`) | 곁에 남음 (`Stay`) | `Ending_Together` — 함께한 아침 | Rope 0, NetPrepared=true, Simon 관계 +1, 함께한 기억 |
| 물가를 살핌 (`ObserveShore`) | 곁에 남음 (`Stay`) | `Ending_Witness` — 호숫가의 증인 | Rope 1, ShoreClueFound=true, 기본 관계, 물가·목격 기억 |
| 시몬을 도움 | 마을로 감 (`Depart`) | `Ending_Departure` — 아직 걷지 않은 길 | 첫 선택 상태 유지, WalkedToVillage=true, 길 위의 기억 |
| 물가를 살핌 | 마을로 감 | `Ending_Departure` — 아직 걷지 않은 길 | 첫 선택 상태 유지, WalkedToVillage=true, 길 위의 기억 |

`Outcome_Stay`는 네 번째 결과가 아니라 둘째 선택 A를 두 결과 중 하나로 연결하는 런타임 라우터 ID다. 세 결과는 제목·서술·이미지·발견 기억을 구분한다. Depart의 두 경로는 동일한 결과 제목을 사용하지만 현재 선택 기록·밧줄·그물·관계 상태를 유지한다. UI의 결과·기억 메뉴가 실제 상태와 함께 보여 주어야 한다.

관계값은 협력 경험을 표시하는 구현 상태다. 신앙, 구원의 우열, 죄의 크기, 예수님의 호감도나 보상 점수로 표시하지 않는다. 여행자의 수선이 많은 고기가 잡힌 사건의 원인이라고 쓰지 않는다. 마을로 떠나는 분기는 플레이어의 시점만 바꾸며 성경 사건을 취소하지 않는다.

## 노드·효과 계약

JSON의 `TextKey`는 `POD.<Id>.Text` 형식의 안정적인 로컬라이제이션 키다. 에디터는 `DA_DawnNarrative`의 `FText`와 실제 텍스처 소프트 참조로 변환한다. 패키지 실행 중 `SourceArt` JSON을 읽지 않는다.

효과 메타데이터는 `SetFlag`, `AddItem`, `RemoveItem`, `ChangeRelationship`만 허용한다. 실제 상태 변화는 C++의 제한된 데모 전용 전이가 적용하며 콘텐츠가 Python·셸·콘솔 명령을 실행하지 않는다. 조사 여부는 `World.inspected` 집합의 단일 상태이며 별도 플래그 복사본을 만들지 않는다. JSON의 `Inspected` 조건은 이 집합을 뜻한다. 선택지 순서·효과·조건·고정 목적지를 검증기가 런타임 계약과 대조한다. CP01은 `Choice_01`, CP02는 `Choice_02` 진입 직전에 생성한다.

현재 `ContentVersion=2`을 고정한다. 버전을 올리거나 효과·조건을 변경할 때에는 `DawnState.h`의 전이·검증, 콘텐츠 검증기의 계약, 에디터 가져오기, 저장 호환성 정책을 함께 검토해야 한다. JSON의 효과만 바꾸어 게임 동작이 바뀐다고 가정하지 않는다.

`Explore`는 조사 대상과 시몬에게 접근하는 게임플레이 진입점이다. 조사 노드는 완료하면 `Explore`로 돌아온다. 시몬과의 대화는 `Simon_Greeting`에서 시작한다. `Scene_Teaching` 뒤의 사건·창작 대화는 `NextNode`로 이어지고, 이미 본 장면 건너뛰기는 CP02 이전의 안정된 시점으로 이동한다.

## 생략과 압축

군중, 야고보와 요한, 다른 배의 동료는 사건 요약에 남겨 두되 개별 3D 캐릭터로 만들지 않는다. 두 배의 항해와 많은 고기 장면은 일러스트와 환경음으로 압축한다. 이 데모의 작은 호숫가가 역사적 갈릴리 지형을 고증해 재현한 것이라고 주장하지 않는다. 예수님·시몬·여행자의 3D 중거리 장면과 초상 일러스트는 서로 다른 표현 수준이며 임시 모델 상태는 AssetManifest/KnownIssues에 별도로 기록한다.

## 실행한 콘텐츠 검사

Linux에서 다음 검사를 실행했다.

```bash
python3 Tools/PathOfDawnUnreal/validate_content.py --self-test --require-art --report Docs/PathOfDawnUnreal/Evidence/content-validation.json
```

중복 ID·텍스트 키, 없는 노드·이미지 참조, 누락 메타데이터, 도달 불가능한 노드·결과, 선택 조합, 체크포인트, 제한된 효과·조건·목적지, 독립 결과 이미지를 검사한다. 잘못된 콘텐츠를 주입한 20개 검사도 모두 거부했다. 이 검사는 C++ 실행, Unreal 에셋 생성, 한국어 UMG 표시, 실제 플레이 검증을 대신하지 않는다.

`--require-art`로 실제 PNG 일곱 장의 디코딩·크기와 `NotoSansKR.otf`의 작성된 텍스트 글리프 포함 여부도 검사해 통과했다. 타이틀 원본은 1672×941로 목표 1920×1080보다 작다는 경고가 남아 있다. 실제 수입된 에셋의 재로드·Cook·UI 노출은 Windows Unreal 환경에서 별도로 검증해야 한다.

## 약 5분 플레이 목표의 현재 근거

v2에서는 초기 조사 뒤에도 그물/물가 행동, 시몬에게 돌아가기, 떠나는 경로의 돌길 이동을 직접 수행한다. 목표 HUD에 거리와 시선 기준 방향을 표시한다. 강제 대기로 시간을 늘리지 않으며, 이미 본 사건은 건너뛸 수 있다. 예수님에게 먼저 말을 걸어도 시몬의 도입 대화를 생략하지 않는다.

경로별 원본 본문은 2,969–3,021자이며 도입·Explore 안내·조사 각 1회를 포함하고 버튼/메뉴는 제외한다. 이는 실제 표시 시간을 뜻하지 않는다. 생성기 중심점 기준 동선은 머무르는 경로 약 53.6–66.5m, 떠나는 경로 약 86.7–99.6m다. 2m 상호작용 반경, 장애물, 읽기·선택 속도에 따라 실제 이동/시간은 달라진다. Unreal 첫 플레이를 녹화하고 도입 시작부터 첫 결과까지 약 5분인지 측정해야 한다. 현재 달성 여부는 미검증이다.

ContentVersion 1 저장은 원본을 보존하며 버전 불일치로 거부한다. 이 환경에서 생성된 실제 Unreal 저장은 없다.
