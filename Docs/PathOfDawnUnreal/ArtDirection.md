# v8 아트 방향과 실제 제작 상태

모래빛 돌과 크림색 린넨, 바랜 청색 겉옷, 올리브색 작업복을 깊은 청색 새벽 그늘과 절제된 금빛으로 묶는다. 작은 호숫가·주요 인물·일러스트에 집중한다. 예수님의 외모는 창작적 재현이며 역사적 초상이나 특정 배우의 복제가 아니다.

현재 가져오기 원본은 `SourceArt/PathOfDawnUnreal/VisualV8/`이다. 기존 `Illustrations/`, `Models/` 27개 원본 파일은 v7 ZIP과 해시를 비교해 보존을 확인했다. 사용자 PC에서는 v7이 실행됐다고 보고받았지만 이 환경에서는 v8 Unreal 화면을 실행하지 못했다.

## 화면과 일러스트

- 새 일러스트 7장을 실제 생성해 저장했다. 예수님 초상을 기준으로 얼굴·크림색 옷·넓은 청색 겉옷을 이어가고 시몬은 짧은 머리·수염·올리브/갈색 옷으로 구별했다.
- 타이틀은 왼쪽의 어두운 호수에 제목·메뉴를 두고 오른쪽 인물과 배를 보여준다. UMG는 전체 화면 원화, 아이보리 제목, 얇은 금색 선, 금색 주요 버튼과 절제된 남색 패널을 사용한다.
- 대화는 비율을 유지한 초상화와 하단 자막, 결과는 전체 화면 원화와 왼쪽 기록·회귀 메뉴다. 제목·대사·버튼은 이미지에 그리지 않는다. 작은 화면과 큰 글자는 패널 스크롤로 접근할 수 있도록 구현했다.
- 세 결과는 함께 그물을 다루는 가까운 세 사람, 물가에서 바라보는 여행자, 마을의 아치를 향해 떠나는 여행자로 구도를 구별한다.
- 얼굴·손·문자·워터마크를 시각 검수했다. 마지막 결과에 처음 생성된 이중 태양은 이미지 생성 도구로 수정했다. 원본 해상도는 가로 1672×941, 초상 1024×1536이다. 1920×1080 목표에는 아직 미달한다.

출처·참조 이미지·수정 이력·해시: [IllustrationManifestV8.json](IllustrationManifestV8.json). [타이틀 UI 참고 이미지](Evidence/UI-V8/title-layout-preview.png)는 **별도 정적 레이아웃 미리보기이며 Unreal 캡처가 아니다.** 실제 UMG의 최종 줄바꿈·크롭·포커스는 로컬 게임에서 확인해야 한다.

## 3D 원본과 레벨

Blender 4.3.2로 캐릭터 3개와 환경 12개를 새로 제작했다. 외부 모델·배우 스캔은 사용하지 않았다. FBX의 실제 형상과 재질 색을 게임으로 가져온다.

- 인물: 연속된 얼굴 면, 코·눈꺼풀·입·수염·머리카락, 소매, 넓게 감싸는 겉옷과 옷 주름, 허리끈, 손과 샌들. 각진 기본 원통·원뿔 형태를 교체했다. 세 모델의 키는 약 1.77~1.80m다.
- 환경: 열린 곡면 목선과 판재·늑골·쇠못, 처진 그물과 수선 상태, 입구가 열린 도기, 늘어진 천막, 크기와 모양이 다른 돌을 맞물린 벽, 판석, 올리브나무, 갈대, 불규칙한 호숫가, 낮은 먼 능선.
- 지면에는 직접 제작한 1024² 모래색/노멀 텍스처를 넣는다. 수면에는 512² 잔물결 노멀과 천천히 움직이는 UV를 사용한다. 외부 이미지 URL을 읽지 않는다.
- 레벨의 보이는 바닥·길·산을 새 메시로 교체하고 나무·갈대·소품을 배치했다. 평평한 숨김 충돌 바닥, 물 진입 경계와 여섯 상호작용 ID는 유지한다. 장식용 돌길·식생의 충돌은 꺼서 이동을 방해하지 않게 했다.

**인물은 여전히 정적 조형 모델이다.** 실제 보행 골격, 얼굴 표정 리그, 립싱크가 없으며 사진 같은 인체 품질을 달성했다고 주장하지 않는다. 대화의 가까운 인물 표정은 일러스트로 전달한다. 신규 형상·조명·Lumen·카메라 충돌·나무 성능은 Unreal에서 검수해야 한다. 인물 약 9만~10.2만 삼각형, 올리브나무 약 12.8만 삼각형이므로 저사양 최적화도 남아 있다.

제작용 Blender 렌더는 `VisualV8/Models/CharacterPreview_*.png`, `EnvironmentPreview.png`다. 레벨 구도 검수는 `Evidence/VisualV8/LevelPreview*.png`를 사용한다. 이들은 **실제 제작 원본의 Blender 렌더이며 Unreal 게임 스크린샷이 아니다.**

원본을 새 비교 폴더에 다시 제작하려면:

```sh
blender -b --python Tools/PathOfDawnUnreal/create_characters_v8.py -- --render --output-dir /tmp/PathOfDawn-Characters-Review
blender -b --python Tools/PathOfDawnUnreal/create_environment_v8.py -- --render --output-dir /tmp/PathOfDawn-Environment-Review
```

생성기는 기존 결과가 있으면 중단한다. 자동 재생성으로 사용자 원본을 덮어쓰지 않는다.

## 가져오기와 보존

`generate_demo_assets.py`는 컴파일된 Editor 모듈을 통해 실제 에셋·맵·Blueprint·Sequencer를 만들고, 별도 Editor 프로세스로 저장된 참조를 다시 확인한다. 기존 사용자 패키지·맵·Blueprint는 보존한다. 변경된 원본과 사용자 편집이 충돌하면 중단한다.

이번 v8은 새 폴더에서 시작한다. 맵·수면·지면 재질에 v8 메타데이터를 저장하고 검증한다. 이전 맵·재질이 남아 있으면 가져오기 전에 중단하므로 옛 화면을 v8 완료로 넘기지 않는다. 에디터 밖에서 가짜 `.uasset`/`.umap` 파일을 만들지 않는다.

사운드는 기존 직접 합성한 물·바람·발걸음·그물 WAV 4개를 유지한다. 음악 트랙·더빙은 없고 합성 환경음도 임시 품질이다. 한국어 폰트는 기존 Noto Sans KR와 OFL 이용 조건을 유지한다.
