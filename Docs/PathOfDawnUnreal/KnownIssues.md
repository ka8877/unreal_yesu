# 현재 남은 작업

## 현재 실행 상태

- 사용자는 v7이 Windows PC에서 실행됐다고 보고했다. 분기 전체·저장 재시작·약 5분 플레이 시간·스트리밍을 검증했다는 보고는 아니다.
- v8은 UI·원화·3D 인물과 환경을 개편한 뒤 Unreal 컴파일·가져오기·재로드·Cook·게임 실행을 다시 확인해야 한다. 이 클라우드 환경에는 Unreal/Windows 빌드 도구/GPU가 없으며 v8 실행 파일·플레이 ZIP·게임 URL은 아직 제공하지 않는다.
- v8 소스는 새 영문 폴더에 압축 해제해야 한다. v7의 `Content`를 복사하면 기존 맵·재질을 보호하기 위해 v8 메타데이터 검사에서 중단한다. 사용자 작업이 담긴 v7 폴더를 삭제하거나 자동 덮어쓰지 않는다.

## 미완료 품질과 동작 검증

- 사용자는 v7의 각진 인물·환경과 화면 구성에 불만을 제기했다. v8은 얼굴·복식의 곡면과 디테일, 환경 형태·소품 배치를 개선하지만 정적 메시다. 골격 보행, 얼굴 리그, 자연스러운 손·시선 애니메이션은 없다. 새 모델의 실제 Unreal 외관과 사용자의 품질 승인은 아직 확인 전이다.
- v8 새 원화 7종도 가로 1672×941, 초상 1024×1536이다. 가로 1920×1080 목표에 미달하며, UMG의 얼굴 크롭·긴 한국어 문장·작은 창 가독성은 게임에서 확인해야 한다.
- v8 타이틀·메뉴·대화·결과 UMG와 새 이미지 연결, 도입·3D 카메라·상호작용·충돌·입력 포커스를 실제 화면에서 확인해야 한다. UI 소스 또는 Blender 렌더만으로 게임의 시각 품질을 확정하지 않는다.
- 전체·음악·효과음 설정은 있으나 음악 트랙과 더빙은 없다. 환경음·발걸음·그물 소리는 직접 합성한 최소 음향이다.
- 최신 목표는 첫 플레이 약 5분이다. v2에 직접 행동·복귀·돌길 이동을 추가했지만 실제 최초 플레이 시간은 측정하지 못했다. 읽기 속도와 건너뛰기로 더 짧아질 수 있다.
- USaveGame 디스크 오류·백업 복구·프로세스 재시작 이어하기 및 저장 위치의 실제 Windows 로그는 미검증이다. 코어 파일 왕복 테스트가 이 검증을 대신하지 않는다.
- Lumen, 1080p 60fps, 메모리·GPU 프레임 시간, 720p/1080p 스트리밍 성능은 측정하지 못했다.
- 생성기는 사용자가 수정한 기존 맵·Blueprint를 보존한다. 맵 제작 스크립트 자체를 변경해도 기존 맵을 자동 재작성하지 않는다. 에디터에서 대상 맵 변경을 검토·저장하거나 새로운 경로로 생성 후 참조를 갱신해야 한다. v2의 Village 액터와 돌길 확장이 빠진 기존 맵은 검증에 실패하도록 한다.

## 스트리밍·배포

- 실제 Unreal 영상·음성·이동·대화·회귀·새로고침·호스트 재시작은 아직 시험하지 못했다. 서버 연결/Origin/동시 접속 제한의 자동 검사는 별도 범위다.
- v6 시작 로그에는 `LogAutomationTest: Error: Condition failed` 15건과 Engine 초기화 전 PixelStreaming2RTC의 `Cannot set target window - GEngine is not valid`가 있다. 이후 에셋 생성은 계속됐으며 이번 Python 중단 원인과 구분한다. 원인은 미확정이고 실제 프로젝트 자동 테스트·스트리밍 단계에서 별도로 확인해야 한다. CUDA context 생성 성공은 인코더 또는 스트리밍 성공이 아니다.
- 기본 제공 서버는 loopback 전용이다. LAN·인터넷 공개, HTTPS/WSS, STUN/TURN, 외부망 테스트는 미구현/미검증이다. 이를 위한 방화벽·라우터·과금 자원을 변경하지 않았다.
- 업데이트는 분리된 새 빌드와 실제 스모크 기록이 있어야 전환한다. 한 번에 그래픽 검증까지 하는 자동 GUI 드라이버는 아직 없어서 현재는 수동 검증 후 전환한다.
- 깨끗한 다른 PC에서 실행 및 ZIP 압축 해제 실행은 미수행이다. 제공 소스 ZIP은 플레이 ZIP이 아니다.

## 검증 범위 주의

생성 원화와 Blender 미리보기는 실제 게임 캡처가 아니다. NullRHI는 작성된 Unreal 자동 테스트용일 뿐 그래픽 증거가 아니다. ASan/UBSan은 실행했지만 컨테이너 ptrace 제약으로 LeakSanitizer 누수 검사는 하지 못했다. [TestReport](TestReport.md)에 통과/실패/미수행을 구분했다.

Windows 더블클릭 시작 도구의 탐색·UBT 실행·실패 전파는 사용자 제공 로그로 확인했다. v5는 앞부분의 컴파일 오류를 화면과 진단 JSON에도 보존한다. 이 추가 기능의 실제 child pwsh 검사는 통과했으나 Windows PowerShell 5.1 재실행은 미검증이다. 현재 도구는 고정된 UE5.8 타깃을 자동 탐색한다. 사용자 PC를 원격으로 연결하거나 설치를 대신 실행한 상태는 아니다.

v6는 에셋 생성의 내부 Python 예외와 전체 Editor 로그를 보존한다. 현재 대화에는 PC 터미널·화면 연결이 없다. 로컬 도구로 실행과 수정을 이어갈 수 있는 새 Windows Codex 작업 절차는 [LocalCodex](LocalCodex.md)에 있다. 실제 로컬 세션에서 사용할 수 있는 화면 조작 도구는 별도로 확인해야 한다.

설치 도우미는 공식 winget 도구 설치를 호출하도록 작성하고 Linux에서 호출 로직만 검사했다. 실제 Windows 설치·권한 요청·설치 완료 후 탐색은 사용자 PC에서 검증해야 한다. Epic 로그인과 UE 설치는 별도 사용자 단계다. Store PowerShell의 실제 실행 경로는 버전 probe 후 허용하도록 v3에서 수정했다.
